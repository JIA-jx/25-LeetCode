## [135. 分发糖果](https://leetcode.cn/problems/candy/submissions/710668490/)

![image-20260322211735826](C:\Users\OMEN\AppData\Roaming\Typora\typora-user-images\image-20260322211735826.png)

```c
#define max(a, b) ((a > b) ? a : b)

int candy(int* ratings, int ratingsSize) {
    int* candy = (int*)malloc(sizeof(int) * ratingsSize);
    for(int i = 0; i < ratingsSize; i++) {
        candy[i] = 1;  //每人至少1颗糖果
    }

    for(int i = 1; i < ratingsSize; i++) {  //先只考虑右边孩子比左边得分高的情况
        if(ratings[i - 1] < ratings[i]) {
            candy[i] = candy[i - 1] + 1;
        }
    }

    for(int i = ratingsSize - 2; i >= 0; i--) {  //再只考虑左边比右边得分高的情况
        if(ratings[i] > ratings[i + 1]) {  //取两者的最大值以确保同时满足两边
            candy[i] = max(candy[i + 1] + 1, candy[i]);
        }
    }
    int res = 0;
    for(int i = 0 ; i < ratingsSize; i++) {
        res +=candy[i];
    }
    return res;
}
```



## [860. 柠檬水找零](https://leetcode.cn/problems/lemonade-change/)

![image-20260322215524042](3.22.assets/image-20260322215524042.png)

```c
bool lemonadeChange(int* bills, int billsSize) {
    int* money = (int*)calloc(2, sizeof(int)); //记录5元和10元的张数
    for(int i = 0; i < billsSize; i++) {
        if(bills[i] == 5) {
            money[0]++;
            continue;
        }
        if(bills[i] == 10) {
            if(money[0] > 0) {
                money[0]--;
                money[1]++;
                continue;
            } else {
                return false;
            }
        }
        if(bills[i] == 20) {
            if(money[1] > 0 && money[0] > 0) { //优先用10元去找零
                money[1]--;
                money[0]--;
            } else if(money[0] >= 3) {
                money[0] -= 3;
            } else {
                return false;
            }
        }
    }
    return true;
}
```
