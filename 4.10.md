## [20. 有效的括号 - 力扣（LeetCode）](https://leetcode.cn/problems/valid-parentheses/)

![image-20260410153631870](C:\Users\OMEN\AppData\Roaming\Typora\typora-user-images\image-20260410153631870.png)

```c
char ret(char x) {
    if(x == '(') return ')';
    if(x == '[') return ']';
    if(x == '{') return '}';
    return 0;
}

bool isValid(char* s) {
    int len = strlen(s);
    if(len % 2 == 1) {
        return false;
    }

    char str[len];
    int top = 0;
    for(int i = 0; i < len; i++) {
        if(s[i] == '(' || s[i] == '[' || s[i] == '{') {
            str[top++] = ret(s[i]);
        }else if(top <= 0) {
            return false;
        }else if(str[--top] != s[i]) {
            return false;
        }
    }
    return top == 0;
}
```



## [1047. 删除字符串中的所有相邻重复项 - 力扣（LeetCode）](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/)

![image-20260410161625041](C:\Users\OMEN\AppData\Roaming\Typora\typora-user-images\image-20260410161625041.png)

```c
char* removeDuplicates(char* s) {
    int len = strlen(s);
    char* stack = (char*)malloc(sizeof(char) * (len + 1));
    int top = 0;

    for(int i = 0; i < len; i++) {
        if(top == 0) {
            stack[top++] = s[i];
        }else if(stack[top - 1] != s[i]) {
            stack[top++] = s[i];
        }else {
            top--;
        }
    }

    stack[top] = '\0';
    return stack;
}
```
